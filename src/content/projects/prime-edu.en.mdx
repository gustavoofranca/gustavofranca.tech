Prime Edu is a Flutter school app with student, teacher and admin profiles. It has a notice board, classes, an events calendar, a profile page and a materials area that searches books through the Google Books API, with previews and downloads.

The code follows a feature-based clean architecture (data, domain and presentation), with Provider and get_it, immutable models with freezed, Hive and shared_preferences for local data, and go_router for navigation. UI components follow Atomic Design, from atoms like buttons and fields up to full pages.

For the project requirements, I built three advanced features: scheduled local notifications (notices, class reminders and deadlines), biometric authentication with fingerprint or face through `local_auth`, and deep links (`primeedu://`) that open a specific notice, class or book.
