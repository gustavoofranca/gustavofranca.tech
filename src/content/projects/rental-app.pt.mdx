O Ignite Premium Rentals é um site de aluguel de carros esportivos. Tem página inicial, catálogo, detalhes de cada carro, checkout com pagamento fictício, login com Google, cadastro simulado e um painel do usuário.

A base é Vite, React e TypeScript, com Tailwind e shadcn/ui (Radix) na interface, React Router nas rotas, TanStack Query para os dados e Firebase (Auth e Firestore) por trás. Os formulários são validados com Zod. O repositório tem Vitest com React Testing Library, ESLint e Prettier, um pre-commit com Husky e lint-staged e um workflow de CI no GitHub Actions.
