Ignite Premium Rentals is a sports car rental site. It has a home page, a catalog, a details page for each car, a checkout with mock payment, Google sign-in, a simulated sign-up and a user dashboard.

It's built on Vite, React and TypeScript, with Tailwind and shadcn/ui (Radix) for the UI, React Router for routing, TanStack Query for data fetching and Firebase (Auth and Firestore) behind it. Forms are validated with Zod. The repo includes Vitest with React Testing Library, ESLint and Prettier, a Husky and lint-staged pre-commit hook, and a GitHub Actions CI workflow.
